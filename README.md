# 🤖⚖️ Джарвис-Юрист (Jarvis) — Legal AI Agent

Открытый проект ИИ-ассистента для юридической работы: исследование правовых вопросов, анализ договоров, конструктор документов и умный поиск по внутреннему архиву.

> ⚠️ Джарвис — вспомогательный инструмент. Он не заменяет профессиональную юридическую консультацию; перед подписанием документы должен проверять юрист.

## Возможности

- **Исследователь** — чат с нейроюристом: анализ договоров, выявление рисков («красные флаги»), предложение безопасных редакций условий. Ответы с цитатами и источниками (КонсультантПлюс, веб-поиск, прикреплённые документы).
- **Конструктор документов** — генерация типовых документов по шаблонам (коммерческие предложения, претензии и т.д.) с реквизитами организации, экспорт в `.docx` и `.pdf`.
- **Внутренний поиск / Архив документов** — индексация входящих и исходящих документов (PDF, DOCX, сканы), быстрая и глубокая аналитика по документу, интеграция с Google Drive, подписание.
- **Панель управления** — статистика по документам, последние чаты, сводка возможных рисков со ссылками на нормы (ГК РФ и др.).
- **Аналитика** — (в разработке).

## Архитектура и стек

Два режима работы LLM:

| Режим | Модель | Когда используется |
|---|---|---|
| Локальный | `qwen3:14b` | Приватная работа без выхода данных наружу |
| Облачный (быстрый) | Anthropic Claude API | Когда нужна скорость и качество ответов |

Обработка документов — полностью локально:

- **OCR** — `qwen3-vl:4b` (распознавание сканов и изображений)
- **Парсинг документов** — [Docling](https://github.com/docling-project/docling) (PDF, DOCX и др.)
- **Умный поиск** — семантический поиск по содержимому файлов, включая PDF

Источники для правового исследования: КонсультантПлюс, веб-поиск, внутренний архив, Google Drive.
