# ⚖️ AI Lawyer Assistant — Юрист-помощник на основе ИИ

Открытый проект интеллектуального ассистента для юридических вопросов.

## О проекте

AI Lawyer Assistant помогает пользователям разбираться в юридических вопросах с помощью современных LLM-моделей:

- 📄 Анализ договоров и документов
- 💬 Ответы на юридические вопросы на понятном языке
- 🔍 Поиск по законодательству и судебной практике
- ✍️ Помощь в составлении типовых документов (заявления, претензии, договоры)

> ⚠️ Проект не является заменой профессиональной юридической консультации.

## Статус

🚧 Проект на стадии проектирования. Roadmap, архитектура и стек обсуждаются в Issues.
