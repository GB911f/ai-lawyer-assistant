# 🤖⚖️ Джарвис-Юрист (Jarvis) — Legal AI Agent

Открытый проект ИИ-ассистента для юридической работы: исследование правовых вопросов, анализ договоров, конструктор документов и умный поиск по внутреннему архиву.

> ⚠️ Джарвис — вспомогательный инструмент. Он не заменяет профессиональную юридическую консультацию; перед подписанием документы должен проверять юрист.

## Возможности

- **Исследователь** — чат с нейроюристом: анализ договоров, выявление рисков («красные флаги»), предложение безопасных редакций условий. Ответы структурированы (коротко → красные флаги → практические рекомендации) и подкреплены цитатами из источников; каждый источник открывается с точной цитатой. К запросу можно подключать источники: файл, Google Drive, КонсультантПлюс, веб-поиск.
- **Конструктор документов** — генерация типовых документов по шаблонам (коммерческие предложения, претензии и т.д.) с реквизитами организации и живым предпросмотром, экспорт в `.docx` и `.pdf`.
- **Внутренний поиск / Архив документов** — индексация входящих и исходящих документов (PDF, DOCX, сканы), быстрая и глубокая аналитика по документу, интеграция с Google Drive, подписание, скачивание PDF.
- **Панель управления** — статистика по документам (всего / проанализировано / ожидают подписи), последние чаты и сводка возможных рисков со ссылками на нормы (например, ГК РФ ст. 330, 333, 521).
- **Аналитика** — (в разработке).

## Архитектура и стек

Два режима работы LLM:

| Режим | Модель | Когда используется |
|---|---|---|
| Локальный | `qwen3:14b` | Приватная работа без выхода данных наружу |
| Облачный (быстрый) | Anthropic Claude API | Когда нужна скорость и качество ответов |

Обработка документов — полностью локально:

- **OCR** — `qwen3-vl:4b` (распознавание сканов и изображений)
- **Парсинг документов** — [Docling](https://github.com/docling-project/docling) (PDF, DOCX и др.)
- **Умный поиск** — семантический поиск по содержимому файлов, включая PDF

Источники для правового исследования: КонсультантПлюс, веб-поиск, внутренний архив, Google Drive.

### Индексация документов

Поиск построен на двух хранилищах: полнотекстовый индекс **SQLite FTS5** и векторное хранилище **Qdrant** (семантический поиск).

| Формат | Как извлекается текст | Куда попадает |
|---|---|---|
| TXT / MD | прямое чтение | FTS или Qdrant |
| DOCX | `python-docx` | обычно Qdrant |
| XLSX | `pandas` / `openpyxl` | обычно Qdrant |
| PDF с текстовым слоем | `pdfplumber` | FTS или Qdrant |
| PDF-скан | рендер страниц в PNG → OCR | Qdrant |
| JPG / PNG / TIFF | OCR | Qdrant |
| Корпус КонсультантПлюс | текстовые парсеры → SQLite FTS5 | FTS |
